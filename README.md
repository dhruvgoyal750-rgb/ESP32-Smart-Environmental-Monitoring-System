# ESP32 Smart Environmental Monitoring System

## Project Overview
An ESP32-based environmental monitoring system designed using EasyEDA Standard.

The system uses a BME280 sensor to collect environmental data and an OLED display to show the readings.

## Hardware Components
- ESP32 DevKit V1
- BME280 Sensor Module
- 0.91-inch OLED Display (I2C)
- LED
- 330Ω Resistor

## Software and Tools
- EasyEDA Standard
- PCB Design and Schematic Capture

## Project Features
- Temperature monitoring
- Humidity monitoring
- Atmospheric pressure monitoring
- OLED-based data display
- Custom PCB design

## PCB Design
The schematic and PCB layout were designed using EasyEDA Standard.

## Design Verification
The PCB passed the EasyEDA Design Rule Check (DRC) with no issues reported.
